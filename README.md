# Klaus 🤖

App Android do Klaus — o robozinho de conversa por voz do Renan, ligado ao servidor do XiaoZhi (xiaozhi.me).

- Carinha animada com 21 expressões (`assets/emojis/`)
- Segurar para falar, conversa automática (mãos livres) e mensagens escritas
- Ativação própria do telemóvel (código no painel do XiaoZhi)
- Atualizações: cada alteração em `main` gera um APK novo em **Releases**; o app avisa e descarrega.

A personalidade, idiomas e base de conhecimento ficam no painel do XiaoZhi e valem na hora para todos os aparelhos.
